# Digital team ADP — May 2026

Interactive briefing deck with live-collab matrix and idea board (Firebase).

## Hosting on GitHub Pages

1. Create a new repo and drop these files at the root (keep the folder structure):
   ```
   index.html
   tweaks-panel.jsx
   assets/…
   ```
2. Repo **Settings → Pages → Source: `main` / root** → save.
3. Wait ~30s. Your deck is live at `https://<you>.github.io/<repo>/`.

Use ← → arrow keys to navigate, or the prev/next buttons.

## Notes

- All PNGs are referenced by their existing names — no renaming needed.
- Firebase realtime collab works as long as the deck is served from a real URL
  (it won't work if you just double-click the HTML locally).
